# Phase 10 Context: Economic Calibration & Shortlist Validation

## Goal

Turn the 26-site PLTU screening dataset into a more decision-oriented shortlist that combines technical screening, economics, port/logistics readiness, and data confidence.

## Trigger

The dashboard summary made the current value clearer, but the user still needs the next practical output: which sites should move into Top 3/Top 5 validation and why.

## Scope

- Add a deterministic shortlist decision matrix.
- Use existing ranking/scoring results, simulation outputs, public port intelligence, and data-confidence metadata.
- Keep all numbers traceable to backend data; no LLM-generated numeric authority.
- Show the result in a new `/shortlist` UI so the user can inspect candidate priorities without reading raw tables only.

## Decision

Phase 10 is milestone v2.1 rather than extending v2.0, because v2.0 Pre-FEED was already completed and verified. Phase numbering continues from Phase 9.
