# Phase 14 Plan: Workflow UX Audit & Simplification

## Success Criteria

1. All primary routes are smoke checked.
2. Key API endpoints are smoke checked.
3. Button/link/form complexity is inventoried.
4. Confusing workflow and operational friction are identified.
5. A simpler target workflow is proposed for the next implementation phase.

## Checks Performed

- Frontend route HTTP checks for 13 main pages.
- Backend API HTTP checks for health, plants, scoring, map, shortlist, validation, evidence, pilot decision, investor, settings, and documents.
- Static scan for buttons, links, forms, destructive actions, and module CTAs.
- UX review against 6 pillars: clarity, hierarchy, task flow, feedback, safety, and cognitive load.

## Result

PASS for runtime availability. FAIL for operational simplicity.

The app is functional, but the user journey is too module-heavy and assumes the user already understands the intended order of operation.
